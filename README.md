# АВАНТА+ — сайт автошколы

Статический сайт (HTML, CSS, JS) без конструкторов. Перенос с Tilda.

## Структура
- `index.html` — главная
- `staff.html` — сотрудники
- `politica.html`, `agreement.html`, `offer.html` — юридические страницы
- `css/style.css`, `js/main.js` — стили и скрипты
- `img/` — изображения
- `send.php` — приём заявок с формы (почта / Telegram)
- `.htaccess` — редиректы со старых адресов Tilda, сжатие, кэш
- `robots.txt`, `sitemap.xml`, `404.html`

## Запуск локально
```bash
python3 -m http.server 8000
```
Открыть http://localhost:8000

## Выкладка на хостинг
1. Загрузить содержимое репозитория в корень сайта (вместе с `.htaccess`).
2. В `send.php` указать почту получателя (`MAIL_TO`) и, при желании, `TG_TOKEN` и `TG_CHAT`.
3. Убедиться, что на хостинге включён PHP и Apache (mod_rewrite).
